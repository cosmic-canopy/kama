kama

A lean, no-GC / RAII language with named params — compiles to portable C.

Install
curl -fsSL https://kama-lang.org/install.sh | sh
curl -fsSL https://kama-lang.org/install.sh | sh
irm https://kama-lang.org/install.ps1 | iex

Auto-detects a C compiler; installs a self-contained build (bundled zig cc) if you don't have one. Update anytime: kama update.

Why kama
  • No GC — deterministic RAII lifetimes, no runtime.
  • Memory-safe by construction, no borrow checker.
  • Transpiles to readable, portable C11 — native or WebAssembly.
